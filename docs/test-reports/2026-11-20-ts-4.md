### 新增元件掛載測試涵蓋範圍（`frontend/test/paSignature.mount.test.ts`，15 項）

1. **`Signatures.vue` 頁首、狀態與權限**：
   - 頁首顯示威脅版本與發布日期、快照時間、AV 與 WildFire 版本及發布日期（TS-Q4）、過期警告（>2 小時）、收集狀態與管理平面 CPU %。
   - 手動重新整理（`canRefresh`）觸發 `refresh()` 後更新 `/status` 冷卻倒數並顯示通知；無 `canRefresh` / `canAi` 權限時隱藏按鈕與 AI 分頁。
   - 快照不可用（`available: false`）時整頁以 `GEmpty` 顯示後端 `message`。
2. **TS-2 審查結論逐項驗證**：
   - `firstVersion === null`：清單（`SignatureListTab`）與抽屜（`SignatureDrawer`，含快照命中與 202 按需命中）皆顯示「未知」，不留空白。
   - `rebuilt === true`：清單、版本差異（`SignatureVersionsTab` 左側版本清單與右側差異區）與抽屜（`SignatureDrawer`）皆明確顯示「這一版差異無法計算」。
   - 歷史不足（`since` 非空）：清單與命中比對（`SignatureHitsTab`）皆顯示「自 YYYY-MM-DD 起統計」。
   - 命中比對 IP / 名稱權限分離：驗證 `can() => true` 但後端回 `includeIps: false` 時畫面**完全不顯示** IP 與名稱；驗證無 `pa-log.read` 但後端回 `includeIps: true` 與 `topSrc`/`topDst` 時畫面**完全依後端回傳**顯示 IP 與 `nameOfIp` 名稱，前端元件不自行判斷權限。
   - 快照查無走 `202` + `lookup` 輪詢：驗證輪詢過程顯示進度、查到時顯示按需查詢明細、查無（`not_found`）時顯示「本機特徵庫查無(可能是病毒 / WildFire / 自訂特徵)」。
3. **規則覆蓋與 AI 摘要分頁**：
   - 規則覆蓋（`SignatureCoverageTab`）：顯示 6 項摘要卡與 `unknown` 警告（「不可當成已有防護，請人工確認」），點規則名稱開啟既有 `PolicyRuleDrawer`。
   - AI 摘要（`SignatureAiTab`）：驗證「AI 建議,需網通確認」只出現在開頭一次且位在回答正文之前（結尾不重複）、正確顯示總高危數與送出筆數及串流內容。
4. **戰情室新特徵命中提示與跨頁抽屜串接**：
   - `mergeNewSignatureHits`：合併 WR-1（5 分鐘）與 WR-2（60 分鐘）之 `newSignatureHits`，同 ID 取較大命中數不重複加總，並依嚴重度 → 命中數排序。
   - `NewSignatureHitsBar.vue`、`EventFeed.vue`、`RiskPanel.vue`、`TrafficLogTable.vue`、`RankingDrawer.vue` 與 `Live.vue`：有權限時點威脅名稱 / 新特徵膠囊開啟 `SignatureDrawer`。
   - `Events.vue`（安全事件 › 威脅排行）、`Search.vue`（Log 明細查詢 THREAT 表格與明細彈窗「特徵碼說明」按鈕）、`SliceDrawer.vue`（時段明細威脅列）：驗證有 `netops.pa-signature.read` 時可點開抽屜，無權限時不渲染可點按鈕。
